# AIML-PROJECT

## Student Insight – Academic Risk Prediction System

## Overview
Student Insight is a web-based academic risk prediction system developed using Python and Flask. It analyzes academic parameters such as attendance, marks, assignments, exam scores, and study hours to classify students into risk categories (Low, Medium, High).

## Technologies Used:
Python,
Flask,
HTML/CSS,
Jinja2,
CSV

## Key Features
Integrated academic performance analysis
Rule-based weighted scoring model
Automated risk classification
Personalized recommendations
CSV-based data storage

## Algorithm
Score = (Attendance × 0.25) + (Internal × 0.25) +
(Assignment × 0.15) + (Exam × 0.25) + (StudyHours × 2)

## Risk Levels:
≥75 → Low Risk
≥50 → Medium Risk
<50 → High Risk

## Run the Project
Install Flask: pip install flask
Run: python app.py
Open: http://127.0.0.1:5000
